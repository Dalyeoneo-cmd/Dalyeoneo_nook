## 이 저장소에 있는 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 홈페이지 화면 전체 |
| `links.html` | 인스타그램 프로필에 거는 링크 페이지 |
| `portfolio-8f3a2c.html` | 포트폴리오 PDF 만드는 페이지 (숨김) |
| `certificate-4b91d7.html` | 작품 보증서 만드는 페이지 (숨김) |
| `_data/` | 작품·전시 이력·학력·사이트 정보 (관리 화면이 저장하는 곳) |
| `content/linkpage.json` | 링크 페이지 내용 |
| `images/` | 작품 사진, 캐릭터 그림, 공유 미리보기 그림 |
| `.pages.yml` | 관리 화면에 어떤 입력 칸을 보여줄지 정하는 설정 |

## 파일 올리기 전 확인

1. 주소창이 **`github.com/Dalyeoneo-cmd/Dalyeoneo_nook`** 인지 본다
2. 이 README가 보이는지 본다 (다른 저장소면 이 글이 없어요)
3. 그 다음에 Add file → Upload files

`index.html` 은 다른 프로젝트에도 같은 이름으로 있어서 제일 헷갈리기 쉬워요.

## 실수로 덮어썼을 때

겁먹지 않아도 돼요. 지난 내용이 전부 남아 있어요.

1. 저장소에서 해당 파일을 클릭
2. 오른쪽 위 **History** 를 누르면 지금까지 올린 기록이 나와요
3. 되돌리고 싶은 시점을 고르고, 그때의 파일을 내려받아 다시 올리면 끝

혼자 하기 어려우면 Claude에게 "포트폴리오 저장소 ○○월 ○○일 버전으로 되돌려줘" 라고 하면 돼요.

## 자주 하는 일

- **작품·전시 추가**: 관리 화면에서. 저장하면 1~2분 뒤 사이트에 반영돼요.
- **화면 디자인 변경**: 파일을 고쳐야 해서 Claude와 함께 작업해요.
- **공유 미리보기 그림 교체**: `images/` 에 **새 이름으로** 올리고 `index.html` 의 `og:image` 주소를 바꿔요. 같은 이름으로 덮어쓰면 카카오톡이 예전 그림을 계속 보여줘요.
